## 六、结论

1. **19:00跑批的时间窗基本合理**：除北向（常20点后才出）和两融（T+1）外全部就绪；北向按T-1标注+次日补数即可
2. 若要北向当日值：可考虑20:00后补拉一次北向datacenter（单独轻量任务），或接受T-1口径
3. 数据宝资金日报实际16:35就发布——历史上17:00跑批的年代该源也够用，无需为它晚跑
4. 所有"当日未出"的源，先怀疑更新时间未到，再怀疑源故障（与2026-10-19用户新规则配套：重试>3次即停，不降级，报告原因）
